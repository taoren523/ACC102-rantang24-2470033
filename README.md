ACC102 Individual Assignment
Ping An Bank (000001) Stock Performance Analysis

Project Introduction
This is an individual assignment for the ACC102 course.
This project uses Python to conduct quantitative analysis on the five-year stock data of Ping An Bank (Stock Code: 000001). It calculates risk and return indicators, and displays stock price trends, return rates, drawdowns and moving average features through visual charts.

Analysis Target
Stock Name: Ping An Bank
Stock Code: 000001
Analysis Period: 2021-07-01 to 2026-04-20
Data Source: Stock trading database

Main Analysis Content
1. Analysis of stock price trend and adjusted closing price
2. 5-day and 20-day Moving Average (MA5 / MA20)
3. Calculation of daily return and cumulative return
4. Annualized return and annualized volatility
5. Maximum Drawdown
6. Sharpe Ratio
7. Statistics of rising, falling and flat trading days
8. Multi-dimensional visual chart display

File Description
`000001_PingAn_Bank.xlsx`: Raw five-year stock data of Ping An Bank
`stock_analysis.py` (or your custom code filename): Main program for stock analysis
`README.md`: Project introduction document

Tools and Libraries Used
Python 3
Pandas
NumPy
Matplotlib

How to Run
After downloading the code and Excel file locally, open Jupyter Notebook, import both the code and the spreadsheet file into Jupyter Notebook, then run the Python file directly. The program will automatically complete the following tasks:
Data loading and cleaning
Financial indicator calculation
Chart generation
Analysis report output

Analysis Output
1. Stock price trend chart
2. Daily return and drawdown chart
3. Stock price and moving average chart
4. Cumulative return trend chart
5. Complete English analysis report (including return performance, risk level, Sharpe ratio and trading statistics)

Assignment Statement
This project is an individual assignment for ACC102. All analyses are based on real historical stock data, aiming to demonstrate the basic methods and result presentation of stock quantitative analysis.
